# Pythonの基本文法を読んでみよう

データ分析でPythonを使いこなすための最初の一歩として、まずは簡単なコードの書き方と読み方に触れていきましょう。

「プログラミング」と聞くと、記号や英単語がたくさん並んでいて難しそうに感じるかもしれません。けれど、いくつかの基本的な決まりごとを知っておけば、メッセージを読むようにすんなり理解できるようになります。

ここでは、コードを形づくる基本要素である**「変数」「データ型」「計算のしかた」「コメント」**のルールを見ていきます。

---

## 1. コードを読むときの基本ルール

Pythonのプログラムには、**「上から下に向かって、1行ずつ順番に実行される」**というシンプルなルールがあります。

はじめに、画面に文字や計算結果を表示させる `print()` という命令を見てみましょう。

```python
# 画面にメッセージを表示するコード
print("こんにちは！Pythonの世界へようこそ。")
print(100 + 200)
```

このコードを実行すると、次のように画面へ表示されます。

```text
こんにちは！Pythonの世界へようこそ。
300
```

`print(...)` のカッコの中に書いた内容がそのまま表示されます。文字を出したいときはダブルクォーテーション `"` やシングルクォーテーション `'` で囲み、数字の計算をしたいときは囲わずにそのまま書くのが約束事です。

---

## 2. 変数：データを一時的に入れておく箱

データ分析では、あつめた数値や言葉をあらかじめ保存しておき、あとから使いたい場面がよくあります。このデータを保存しておく場所を**「変数（へんすう）」**と呼びます。

変数を使うときは、`変数名 = 保存したいデータ` という形で書きます。

> 画像挿入予定：Pythonの変数と基本データ型の概念図

```python
# 変数に数値を代入する
price = 1500
tax_rate = 0.1

# 変数を使って計算する
tax_amount = price * tax_rate
total_price = price + tax_amount

print(total_price)
```

プログラミングでの `=` は「左右が等しい」という意味ではなく、**「右側の値を、左側の変数という箱に入れる」**という意味になります。

一度変数に入れておけば、その名前を使っていつでも数値を呼び出したり、計算に使いまわしたりできて便利です。

---

## 3. よく使うデータ型（数値と文字列）

Pythonであつかうデータには、いくつか**「型（データの種類）」**があります。データ分析で最初におさえておきたい代表的な型は次の4つです。

| データ型 | どんなデータ？ | 例 |
| :--- | :--- | :--- |
| **整数型 (int)** | 小数点のない整数 | `10`, `-5`, `0` |
| **浮動小数点数型 (float)** | 小数点のある数値 | `3.14`, `0.5`, `-1.2` |
| **文字列型 (str)** | 文字の並び（クォートで囲む） | `"データ"`, `'Python'` |
| **真偽値型 (bool)** | 正しいか（True）誤りか（False） | `True`, `False` |

型によってできる操作が変わります。たとえば数字同士の `10 + 20` は `30` になりますが、文字同士の `"10" + "20"` は `"1020"` と文字がつながる動作になります。

コードがうまく動かないときは、「数字のつもりで書いたデータが文字になっていないかな？」と確認してみるのがポイントです。

---

## 4. コードに説明をそえるコメント

コードの中に `#`（ハッシュマーク）を書くと、その行の `#` よりうしろの部分はプログラムとして実行されなくなります。これを**「コメント」**と呼びます。

```python
# これはコメントです。プログラムの実行には影響しません。
sales = 50000  # 本日の売上金額（円）
```

コメントは、「このコードで何をしているのか」「どうしてこの計算をしたのか」を自分や仲間にわかりやすく伝えるためのメモです。あとで読み返したときに迷わないよう、ひとことメモを残す癖をつけておくと安心です。

---

## 5. まとめ

Pythonの基本文法は、とてもシンプルで素直です。

- コードは上から順に実行される
- `print()` で画面に表示できる
- `変数名 = 値` でデータに名前をつけて保存できる
- 数値と文字は型が分かれている
- `#` を使ってメモを残せる

この基本を知っておくだけで、コードを見たときの抵抗感がぐっと減ります。つぎは、たくさんのデータをまとめてあつかう「リスト」や「辞書」、処理を枝分かれさせる文法について見ていきましょう。
