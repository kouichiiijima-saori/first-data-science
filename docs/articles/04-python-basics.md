# Pythonの基本文法を読んでみよう

データ分析でPythonを使うための第一歩として、まずはPythonプログラムの最も基礎的な書き方と読み方を学んでいきましょう。

プログラミングと聞くと「英単語や記号が複雑に並んでいて難しそう」と感じるかもしれませんが、ルールさえ知っていれば英語の文章を読むように理解できます。

本記事では、プログラミングの最小単位である**「変数」「データ型」「演算」「コメント」**の基本ルールを解説します。

---

## 1. Pythonのコードを読む第一歩

Pythonのプログラムは、原則として**「上から下へ、1行ずつ順番に実行される」**というルールがあります。

まずは、画面に文字や計算結果を表示する基本命令 `print()` を見てみましょう。

```python
# 画面にメッセージを表示するコード
print("こんにちは！Pythonの世界へようこそ。")
print(100 + 200)
```

このコードを実行すると、次のように表示されます。

```text
こんにちは！Pythonの世界へようこそ。
300
```

`print(...)` のカッコの中に書いた内容が出力されます。文字を表示したい場合はダブルクォーテーション `"` やシングルクォーテーション `'` で囲み、数字の計算を行いたい場合は囲わずにそのまま記述します。

---

## 2. 変数：データを保存する箱

データ分析では、集めた数値やテキストを一時的に保存しておく場所が必要です。このデータの保存場所のことを**「変数（へんすう）」**と呼びます。

変数を使うときは、`変数名 = 保存したいデータ` という形で書きます。

![Pythonの変数と基本データ型の概念図]([画像挿入位置: Pythonの変数と基本データ型の概念図])

```python
# 変数に数値を代入する
price = 1500
tax_rate = 0.1

# 変数を使って計算する
tax_amount = price * tax_rate
total_price = price + tax_amount

print(total_price)
```

ここでの `=` は数学の「等しい」という意味ではなく、**「右辺の結果を左辺の変数に入れる（代入する）」**という意味になります。

一度変数に保存しておけば、後から何度でもその名前を使ってデータを呼び出したり、計算に使ったりできます。

---

## 3. 基本的なデータ型（数値と文字列）

Pythonで扱うデータには**「データ型（種類）」**があります。データ分析で特によく使う基本型は以下の通りです。

| データ型 | 概要 | 例 |
| :--- | :--- | :--- |
| **整数型 (int)** | 小数点を含まない整数 | `10`, `-5`, `0` |
| **浮動小数点数型 (float)** | 小数点を含む実数 | `3.14`, `0.5`, `-1.2` |
| **文字列型 (str)** | 文字の並び（クォートで囲む） | `"データ"`, `'Python'` |
| **真偽値型 (bool)** | 正しいか間違いかを表す値 | `True`, `False` |

型によって行える操作が異なります。例えば、数値同士なら `10 + 20` は `30` になりますが、文字列同士の `"10" + "20"` は `"1020"` という文字の結合になります。

データ分析でエラーが出たときは、「数値として扱いたいデータが文字列になっていないか」を確認することがよくあります。

---

## 4. コードに見やすさと説明を加えるコメント

コードの中に `#`（ハッシュマーク）を書くと、その行の `#` 以降はプログラムとして実行されなくなります。これを**「コメント」**と呼びます。

```python
# これはコメントです。プログラムの実行には影響しません。
sales = 50000  # 本日の売上金額（円）
```

コメントは、自分やチームメンバーに対して「このコードは何をしているのか」「なぜこの計算をしているのか」を日本語で説明するために使用します。後から読み返した時に分かりやすいよう、こまめにコメントを残す癖をつけておくと良いでしょう。

---

## 5. まとめ

Pythonの基本文法はとてもシンプルです。

- コードは上から下へ実行される
- `print()` で画面に出力できる
- `変数名 = 値` でデータに名前をつけて保存できる
- 数値（`int`/`float`）と文字列（`str`）は区別される
- `#` でコメントが書ける

この基本を押さえておくだけで、プログラミングのコードを読む抵抗感が一気になくなります。次の記事では、複数のデータをまとめて扱う「リスト」や「辞書」、処理を制御する文法について学んでいきましょう。
