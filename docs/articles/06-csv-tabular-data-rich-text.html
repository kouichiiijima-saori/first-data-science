ビジネスや研究の現場で最もよく目にするデータの形が「表形式データ（Tabular Data）」です。そして、その表データをファイルとして保存したり受け渡したりするときによく使われるのがCSV（シーエスブイ）ファイルです。

ここでは、表形式データの基本的な見方から、CSVファイルの仕組み、Excelなどの表計算ソフトとの違いについてやさしく紐解いていきましょう。

1. 表形式データってどんな形？

表形式データとは、データを「行（Row）」と「列（Column）」のマス目に並べて整理した構造のことです。

身近な例としては、表計算ソフトで作った売上メモや名簿、お店の在庫リストなどが当てはまります。

  • 行（Row / レコード）: 1件ごとのデータ（例：顧客Aさんの情報、1月1日の売上記録）を表します。横方向の並びです。
  • 列（Column / カラム・属性）: データの項目（例：お名前、年齢、購入金額、日付）を表します。縦方向の並びです。
  • ヘッダー（Header）: 表の一番上の行にある項目名のことです。各列にどんなデータが入っているかを教えてくれます。

2. CSVファイルの仕組み

CSVとは「Comma-Separated Values」の略で、「カンマで区切られた値」という意味を持ちます。

表計算アプリで見るときれいな表に見えますが、メモ帳などのテキストエディタで中身を開くと、次のように文字とカンマだけで書かれています。

カンマが列の区切り、改行が行の区切りを表しています。文字飾りのないシンプルなテキストデータなので、ファイルサイズが小さく扱いやすいのがメリットです。

3. なぜデータ分析でCSVがよく使われるのか

世の中にはいろいろなファイル形式がありますが、データ分析でCSVがよく選ばれるのには3つの理由があります。

  1. いろいろなアプリや環境で開ける: パソコンの種類や使っているソフトを問わず、スムーズに読み書きできます。
  2. ファイルが軽くて扱いやすい: 余計なデザイン情報が含まれないため、データが大きくなっても比較的軽くあつかえます。
  3. プログラムとの相性がよい: Pythonのpandasなどのライブラリを使うと、短く簡単なコードで読み込んで計算できます。

4. CSVデータをあつかうときのポイント

手軽で便利なCSVですが、使うときに知っておきたい小さな注意点もあります。

ひとつは、文字コードの違いによる文字化けです。使っている環境（UTF-8やShift_JISなど）が異なると、日本語が正しく表示されないことがあります。

また、データ項目の中にカンマや改行が含まれる場合は、項目全体をダブルクォーテーションで囲むルールがあります。データ内にダブルクォーテーション自体が含まれる場合は、CSV内部では2つ重ねて表示して区別します。実務ではこうした基本的な決まりごとを頭の片隅に置いておくと安心です。

5. まとめ

CSVは、行と列からなるシンプルな表データを、文字とカンマで素直に表現したファイル形式です。

「行・列・ヘッダー」という表の構造を意識できるようになると、Pythonや分析ツールでの整理がぐっと楽になります。つぎは、分析に入る前におこなう大切な作業「データの整理と前処理」について見ていきましょう。
