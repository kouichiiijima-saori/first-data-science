ビジネスや研究の現場で広く扱われるデータ形式の代表例が「表形式データ（Tabular Data）」です。そして、その表形式データをファイルとして保存・交換するための標準的なフォーマットがCSV（シーエスブイ）ファイルです。

本記事では、表形式データの基本構造から、CSVファイルの仕組み、Excel等のスプレッドシートとの違いについて分かりやすく解説します。

1. 表形式データとは何か？

表形式データとは、データを「行（Row）」と「列（Column）」の格子状（マトリクス）に並べて整理した構造のことです。

身近な例としては、表計算ソフトで作った売上管理表や名簿、データベースのテーブルなどが当てはまります。

  • 行（Row / レコード）: 1件ごとのデータ（例：顧客Aさんのデータ、1月1日の売上データ）を表します。横方向の並びです。
  • 列（Column / カラム・属性）: データの項目（例：氏名、年齢、購入金額、日付）を表します。縦方向の並びです。
  • ヘッダー（Header）: 表の最上行にある項目名のことです。各列にどんなデータが入っているかを定義します。

2. CSVファイルの構造と仕組み

CSVとは「Comma-Separated Values」の略で、日本語では「カンマで区切られた値」という意味になります。

見た目は表計算ソフトのような表に見えますが、テキストエディタで中身を開くと、次のように文字とカンマだけで構成されています。

画像挿入予定：カンマ区切りテキストから表（行・列・ヘッダー）への変換図

実際のCSVファイルの中身の例：

日付,商品名,単価,数量
2026-04-01,リンゴ,150,3
2026-04-01,バナナ,100,5
2026-04-02,オレンジ,120,2

カンマ `,` が列の区切りを表し、改行が行の区切りを表しています。装飾や色情報を持たない単純なテキストデータであるため、容量が小さく扱いやすいのが特徴です。

3. なぜデータ分析でCSVがよく使われるのか

独自形式のファイルなど多様なデータ形式がある中で、データ分析でCSVが採用される理由は主に3つあります。

  1. 汎用性が高く異なるシステム間で共有しやすい: OSやソフトウェアを問わず、多様なツールで読み書きが可能です。
  2. ファイル構造がシンプルで軽量: テキスト形式のため他のソフトウェアと連携しやすく、大きなデータセットでも比較的軽量に扱えます。
  3. プログラムでの処理が容易: Pythonのpandasなどのライブラリを使うと、簡潔なコードでデータを読み込んで分析を開始できます。

4. CSVデータを扱う際の注意点

便利で扱いやすいCSVですが、いくつか留意すべきポイントもあります。

まず、文字コードの違いによる文字化けです。環境によって（UTF-8やShift_JISなど）使用される文字コードが異なる場合、日本語が正しく表示されないことがあります。

また、データ項目（セル）の値自体にカンマや改行、引用符が含まれる場合は、データをダブルクォーテーション `""` で囲むエスケープルールが必要になります。実務ではこうした構造上のルールを意識することが大切です。

5. まとめ

CSVは、行と列からなるシンプルな表形式データを文字とカンマで表現した、データ分析の基本ファイルフォーマットです。

データの構造（行・列・ヘッダー）を意識できるようになると、Pythonや各種分析ツールを使った集計がスムーズになります。次の記事では、分析を開始する前に行う重要な作業「データの整理と前処理」について学んでいきましょう。
