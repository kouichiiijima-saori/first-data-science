データをあつめてきれいに整えたら、つぎはそのデータ全体が「どんな特徴を持っているのかな」と要約して把握します。このように全体の特徴をギュッとひとつの数字に縮めて表したものを「要約統計量（基本統計量）」と呼びます。

ここでは、データを代表する3つの指標「平均値」「中央値」「最頻値」の違いと、データの散らばり具合を表す「ばらつき」の見方をやさしく解説します。

1. データ全体の特徴をつかむ代表値とは

たとえば「テストの点数」や「商品の購入金額」といったたくさんのデータを人に伝えたり把握したりするとき、ひとつひとつの数値を読み上げるのは大変です。

データ全体の特徴を代表して表す指標を「代表値」と呼びます。なかでもよく使われるのが、平均値・中央値・最頻値の3つです。

2. 平均値・中央値・最頻値の違いと使い分け

それぞれの意味と得意な場面を比べてみましょう。

  • 平均値（Mean）: すべてのデータを足し合わせて、データの数で割った値です。親しみやすい指標ですが、極端に大きい数値や小さい数値（外れ値）があると引っ張られやすい性質があります。
  • 中央値（Median）: データを小さい順に並べ替えたとき、ちょうど真ん中にくる値です。極端な外れ値があっても影響を受けにくいのが強みです。
  • 最頻値（Mode）: データの中で最も頻繁に出てくる値です。洋服のサイズやアンケートの選択肢など、カテゴリごとの登場回数を見たいときによく使われます（※同じ一番多い回数の値が複数ある場合もあります）。

3. 外れ値に強い中央値の大切さ

平均値だけでデータを判断すると、実際の感覚とずれてしまうことがあります。わかりやすい例が「世帯の貯蓄額」や「年収」などのデータです。

画像挿入予定：外れ値が平均値と中央値に与える影響の比較図

一部の極端に高い数値が存在すると、平均値が大きく引き上げられ、多くの人の実感よりも高い数値に見えてしまうことがあります。

このように極端な値が含まれていそうなデータでは、「平均値」だけでなく「中央値」も合わせて見ておくことが大切です。

4. データの「ばらつき」をあわせて見る

代表値（中心の位置）がわかったら、つぎはデータが中心のまわりにどれくらい散らばっているかという「ばらつき」を確認します。

平均値が同じ「50点」のテストが2つあっても、「全員が45〜55点の間に集まっているテスト」と「0点と100点に分かれているテスト」では、データの広がり方がまったく異なります。

  1. 範囲（レンジ）: 一番大きい値から一番小さい値を引いた差です。データ全体の広がり幅がわかります。
  2. 標準偏差（Standard Deviation）: データが平均値のまわりに、どの程度散らばっているかを表す指標です。標準偏差が小さいほど、データが平均の近くにキュッと集まっていることを示します。

5. まとめ

データの特徴を正しく読み解くには、平均値だけでなく中央値や最頻値との関係を見比べたり、標準偏差などのばらつきと合わせて見たりすることが大切です。
