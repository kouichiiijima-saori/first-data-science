データを集めて綺麗に整理したら、次はそのデータ全体が「どんな特徴を持っているのか」を1つの数値でキュッと要約したくなります。この要約した数値を「要約統計量（基本統計量）」と呼びます。

本記事では、データを代表する3つの値「平均値」「中央値」「最頻値」の違いと、データの広がり具合を表す「ばらつき」の捉え方を解説します。

1. データの全容をつかむ代表値とは

例えば「あるクラスのテスト結果」や「自社商品の購入金額」といった大量のデータを人に説明するとき、1件ずつの数値を読み上げるわけにはいきません。

データ全体の特徴を1つの数値で代表して表す指標を「代表値（中心傾向の指標）」と呼びます。代表的なものに平均値・中央値・最頻値の3つがあります。

2. 平均値・中央値・最頻値の違いと使い分け

それぞれの定義と特徴を比べてみましょう。

  • 平均値（Mean）: すべてのデータの合計値をデータ数で割った値。最も一般的ですが、極端に大きな値や小さな値（外れ値）に引っ張られやすい弱点があります。
  • 中央値（Median）: データを小さい順に並べ替えたとき、ちょうど真ん中にくる値。極端な外れ値の影響を受けにくいのが強みです。
  • 最頻値（Mode）: データの中で最も頻繁に（回数多く）登場する値。アンケートの選択肢や商品の靴のサイズなど、カテゴリデータでよく使われます。

3. 外れ値に強い中央値の重要性

平均値だけでデータを判断すると、大きな誤解を生むことがあります。典型的な例が「世帯年収」や「貯蓄額」のデータです。

一部の超富裕層（極端な大金持ち）が存在すると、平均値が一気に引き上げられてしまい、大半の一般的な人の実感とかけ離れた数値になってしまいます。

このような外れ値が含まれる可能性があるデータでは、「平均値」だけでなく「中央値」もあわせて確認することが実務上非常に重要です。

4. データの「ばらつき」を評価する

代表値（中心）が分かったら、次はデータのデータが中央のまわりにどれくらい散らばっているかという「ばらつき」を確認します。

平均値がどちらも「50点」の2つのテストがあっても、「全員が45点〜55点に集中しているテスト」と「0点と100点に極端に分かれているテスト」では、実態が全く異なります。

  1. 範囲（レンジ）: 最大値から最小値を引いた差。データの全幅がわかります。
  2. 標準偏差（Standard Deviation）: 各データが平均値からどれくらい離れているかの平均的な距離を表す指標。標準偏差が小さいほど「ばらつきが少なく平均付近にデータが集中している」ことを意味します。

5. まとめ

データ全体の特徴を把握するためには、単に平均値を計算するだけでなく、中央値や最頻値との違いを意識し、ばらつき（標準偏差など）までセットでみることが大切です。
