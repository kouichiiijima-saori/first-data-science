データを集めて整理したら、次はそのデータ全体が「どのような特徴を持っているか」を要約して把握します。この要約した数値を「要約統計量（基本統計量）」と呼びます。

本記事では、データを代表する3つの値「平均値」「中央値」「最頻値」の違いと、データの散らばり具合を表す「ばらつき」の考え方を解説します。

1. データの全容をつかむ代表値とは

例えば「テストの点数」や「商品の購入金額」といった大量のデータを把握・共有する際、1件ずつの数値をそのまま見ても全体像は掴めません。

データ全体の特徴を代表して表す指標を「代表値」と呼びます。代表的なものに平均値・中央値・最頻値の3つがあります。

2. 平均値・中央値・最頻値の違いと使い分け

それぞれの定義と特徴を比べてみましょう。

  • 平均値（Mean）: すべてのデータの合計値をデータ数で割った値。一般的ですが、極端に大きな値や小さな値（外れ値）がある場合に影響を受けやすい性質があります。
  • 中央値（Median）: データを順に並べ替えたとき、ちょうど真ん中に位置する値。外れ値の影響を受けにくい特徴があります。
  • 最頻値（Mode）: データの中で最も頻繁に登場する値。商品サイズやアンケートの選択肢など、カテゴリごとの出現回数を確認する際にも用いられます（※同率の最多値が複数存在する場合もあります）。

3. 外れ値に強い中央値の重要性

平均値だけでデータを判断すると、実態と異なる印象を受けることがあります。典型的な例が「世帯の貯蓄額」などのデータです。

画像挿入予定：外れ値が平均値と中央値に与える影響の比較図

一部の極端に高い数値が存在すると、平均値が引き上げられてしまい、全体の大半の値よりも高くなることがあります。

このように外れ値の影響が懸念されるデータでは、「平均値」だけでなく「中央値」もあわせて確認することが推奨されます。

4. データの「ばらつき」を評価する

代表値（中心）を把握したら、次はデータが中心のまわりにどれくらい散らばっているかという「ばらつき」を確認します。

平均値が同じ「50点」の2つのテストがあっても、「全員が45〜55点に集中している状態」と「0点と100点に極端に分かれている状態」では、データ構造が異なります。

  1. 範囲（レンジ）: 最大値と最小値の差。データの分布の広がりを示します。
  2. 標準偏差（Standard Deviation）: 各データが平均値からどの程度散らばっているか度合いを表す指標。標準偏差が小さいほど、データが平均の近くに集まっていることを示します。

5. まとめ

データ全体の特徴を捉えるには、平均値だけでなく中央値や最頻値との関係を考慮し、ばらつき（標準偏差など）と合わせて総合的に確認することが大切です。
