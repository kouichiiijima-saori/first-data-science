# リスト・辞書・条件分岐・繰り返し

前回の記事では、1つの変数に1つのデータを保存する基本を学びました。けれど実際のデータ分析では、何十件、何千件といったたくさんのデータをまとめてあつかう場面が多くあります。

ここでは、複数のデータをまとめて管理する**「リスト」**と**「辞書」**、そして条件によって動きを変える**「条件分岐（if文）」**、同じ作業を自動でくり返す**「繰り返し（for文）」**を紹介します。

---

## 1. 複数のデータをまとめてあつかう仕組み

データ分析では、「日々の売上データの一覧」や「お客様の属性情報」のように、関連するデータをグループにしてあつかいます。

Pythonには、目的に合わせてデータをまとめておく仕組み（データ構造）が用意されています。その代表格が「リスト」と「辞書」です。

---

## 2. リスト：順番にデータを並べておく

**リスト**は、複数のデータを順番に並べて保管する仕組みです。全体を `[` `]`（角カッコ）で囲み、あいだをカンマ `,` で区切ります。

```python
# 売上データのリストを作成
sales_list = [1200, 1500, 1800, 2100, 1600]

# リストの要素を取り出す（インデックスは0から始まる）
print(sales_list[0])  # 1200が表示される
print(sales_list[2])  # 1800が表示される
```

リストの中にあるデータには、先頭から順に `0, 1, 2, 3...` という番号（インデックス）が割り当てられます。一番最初のデータが `1` ではなく `0` 番目から始まるのが小さなポイントです。

---

## 3. 辞書：見出し（キー）と値をセットにする

**辞書（ディショナリ）**は、データに名前（キー）をつけて、`キー: 値` のペアで管理する仕組みです。全体を `{` `}`（波カッコ）で囲みます。

```python
# 顧客情報の辞書を作成
user_info = {
    "name": "田中太郎",
    "age": 30,
    "city": "東京"
}

# キーを指定して値を取り出す
print(user_info["name"])  # 田中太郎が表示される
print(user_info["city"])  # 東京が表示される
```

辞書を使うと、数字の番号ではなく「"name"」「"age"」といった分かりやすい名前でデータを取り出せます。表データの1行分（レコード）を表すときなどに重宝します。

---

## 4. 条件分岐（if文）と繰り返し（for文）

データをまとめられるようになったら、次はプログラムに自動判断や繰り返しを任せてみましょう。

### 条件分岐（if文）
「もし条件Aを満たせば処理1を行い、そうでなければ処理2を行う」というように、状況に合わせて処理を分岐させます。

```python
score = 85

if score >= 80:
    print("合格です！素晴らしい成績ですね。")
else:
    print("もう少し頑張りましょう。")
```

Pythonでは、インデントを使って処理の範囲を示します。一般的には半角スペース4つを使います。

### 繰り返し（for文）
リストに入ったたくさんのデータに対して、1つずつ同じ処理を順番に行います。

```python
sales_list = [1200, 1500, 1800]

# リストの要素を1つずつ取り出して処理する
for sales in sales_list:
    print(f"本日の売上は {sales} 円です。")
```

このコードを実行すると、リストにある数値が順番に取り出され、メッセージが自動でくり返し表示されます。データが100件になっても、同じ書き方で一括処理できます。

---

## 5. まとめ

今回は、Pythonでまとまったデータをあつかうための基本を見てきました。

- **リスト (`[]`)**: データを順番に並べる（0番目から数える）
- **辞書 (`{}`)**: データに「キー: 値」の名前をつけて管理する
- **条件分岐 (`if`)**: 条件によって動きをわける
- **繰り返し (`for`)**: たくさんのデータに同じ処理を自動でくり返す

これらを組み合わせることで、複雑な作業をプログラムに任せられるようになります。つぎは、データ分析の実務で欠かせない「CSVと表形式データ」の基本に進みましょう。
