# リスト・辞書・条件分岐・繰り返し

前回の記事では、1つの変数に1つのデータを保存する基本文法を学びました。しかし、実際のデータ分析では複数件から数万件といったデータをまとめて処理する必要があります。

今回は、複数のデータをまとめて管理する**「リスト」**と**「辞書」**、そしてデータの条件によって処理を変える**「条件分岐（if文）」**、同じ処理を繰り返す**「繰り返し（for文）」**について解説します。

---

## 1. 複数のデータをまとめて扱う構造

データ分析では、「売上データの一覧」や「顧客情報の属性」のように、複数の関連するデータをまとめて扱います。

Pythonでは、用途に応じてデータを格納するためのデータ構造が用意されています。代表的なものが「リスト」と「辞書」です。

> 画像挿入予定：リスト（順序構造）と辞書（キーと値のペア）のデータ構造比較

---

## 2. リスト（順序のあるデータの集まり）

**リスト**は、複数のデータを順番に並べて管理するための仕組みです。全体を `[` `]`（角カッコ）で囲み、各要素をカンマ `,` で区切ります。

```python
# 売上データのリストを作成
sales_list = [1200, 1500, 1800, 2100, 1600]

# リストの要素を取り出す（インデックスは0から始まる）
print(sales_list[0])  # 1200が表示される
print(sales_list[2])  # 1800が表示される
```

リスト内の各データには、先頭から `0, 1, 2, 3...` という番号（インデックス）が割り当てられます。先頭の要素が `1` ではなく `0` から始まる点に注意しましょう。

---

## 3. 辞書（キーと値のペア）

**辞書（ディショナリ）**は、データに項目名（キー）をつけて、`キー: 値` のペアで管理する仕組みです。全体を `{` `}`（波カッコ）で囲みます。

```python
# 顧客情報の辞書を作成
user_info = {
    "name": "田中太郎",
    "age": 30,
    "city": "東京"
}

# キーを指定して値を取り出す
print(user_info["name"])  # 田中太郎が表示される
print(user_info["city"])  # 東京が表示される
```

辞書を使うと、数字のインデックスではなく「"name"」「"age"」といった分かりやすい名前でデータを取り出すことができます。表の1行分（レコード）を表現する際にも役立ちます。

---

## 4. 条件分岐（if文）と繰り返し（for文）

データ分析の自動化には、プログラムの制御構文が欠かせません。

### 条件分岐（if文）
「もし条件Aを満たすなら処理1を行い、そうでなければ処理2を行う」という条件に応じた処理の切り替えを行います。

```python
score = 85

if score >= 80:
    print("合格です！優れた成績です。")
else:
    print("もう少し頑張りましょう。")
```

Pythonでは、条件を満たした時の処理を**インデント（文字の先頭にスペース4個を入れる段落下げ）**で表現します。

### 繰り返し（for文）
リストに入った複数のデータに対して、1つずつ同じ処理を繰り返し適用します。

```python
sales_list = [1200, 1500, 1800]

# リストの要素を1つずつ取り出して処理する
for sales in sales_list:
    print(f"本日の売上は {sales} 円です。")
```

このコードを実行すると、リスト内のデータが順番に取り出され、メッセージが自動的に出力されます。データの件数が多くなっても、たった数行の `for` 文で一括処理を行えます。

---

## 5. まとめ

今回は、実用的なPythonプログラムの根幹となる要素を学びました。

- **リスト (`[]`)**: データを順番に並べて管理する（インデックスは0から）
- **辞書 (`{}`)**: データを「キー: 値」のペアで管理する
- **条件分岐 (`if`)**: 条件によって処理を分ける
- **繰り返し (`for`)**: 複数のデータに対して同じ処理を連続実行する
