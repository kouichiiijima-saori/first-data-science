ここまで記事1〜9を通して、データサイエンスの考え方、分析の流れ、Python、CSVデータ、前処理、基本となる数値の見方、そしてグラフの作り方を学んできました。

この記事ではまとめとして、架空のカフェ店舗の売上データを使い、CSVを読み込んで、集計し、グラフにする流れを実際に体験してみましょう。

使うサンプルデータは、演習用CSV（sales_data.csv）をダウンロードして用意できます。Google ColabやJupyter Notebookで試すときは、このCSVファイルをノートブックと同じ場所に置いてください。

1. 演習のシナリオと目的

あなたがカフェ店舗のデータを見て、お店のオーナーから「どの商品がよく売れているのか、まずはざっくり知りたい」と相談されたと想定します。

今回は、次の順番で進めます。

  1. CSVを読み込む
  2. データの先頭や列名を確認する
  3. 売上合計と売上平均を計算する
  4. 商品別に売上を集計する
  5. カテゴリ別に売上を集計する
  6. 一番売上が大きい商品を確認する
  7. 棒グラフで商品別の売上を比べる

今回は外部APIやインターネット接続は使いません。pandasとmatplotlibだけで進めます。

2. サンプルCSVの中身

sales_data.csvには、16行の売上データが入っています。列の意味は次のとおりです。

  • date: 売上日
  • product: 商品名
  • category: カテゴリ
  • quantity: 販売数量
  • unit_price: 単価
  • sales: 売上金額（quantity × unit_price）

このデータは学習用に作成した架空データです。実在する店舗やお客様の情報は含まれていません。

3. PythonでCSVを読み込む

まずはpandasを読み込み、CSVファイルを読み込みます。ColabやJupyterで試す場合は、sales_data.csvをノートブックと同じ場所に置いてから実行してください。

import pandas as pd
import matplotlib.pyplot as plt
df = pd.read_csv("sales_data.csv")

読み込めたら、最初の5行を見てみます。

df.head()

次のように、日付、商品名、カテゴリ、数量、単価、売上金額が表として表示されます。

1  2026-04-02   カフェラテ      ドリンク         9         450   4050
2  2026-04-03      紅茶      ドリンク         7         400   2800
3  2026-04-04  サンドイッチ       フード         8         650   5200

4. 行数や列名を確認する

データ分析では、いきなり計算する前に、どれくらいの行数があるのか、どんな列があるのかを確認します。

print("行数と列数:", df.shape)
print("列名:", df.columns.tolist())

このCSVでは、次の結果になります。

行数と列数: (16, 6)
列名: ['date', 'product', 'category', 'quantity', 'unit_price', 'sales']

5. 売上合計と売上平均を求める

次に、sales列を使って売上合計と売上平均を計算します。

total_sales = df["sales"].sum()
average_sales = df["sales"].mean()
print(f"売上合計: {total_sales:,}円")
print(f"売上平均: {average_sales:,.3f}円")

実行結果は次のとおりです。

売上合計: 70,250円
売上平均: 4,390.625円

ここでの売上平均は、1行あたりの平均売上です。日ごとの平均ではなく、CSVに入っている各売上記録の平均として見ています。計算結果は正確には4,390.625円で、ざっくり見ると約4,391円です。

6. 商品別に売上を集計する

どの商品が売上に大きく貢献しているのかを見るため、product列でまとめてsales列を合計します。

product_sales = df.groupby("product")["sales"].sum().sort_values(ascending=False)
print(product_sales)

実行結果は次のとおりです。

product
サンドイッチ    16250
ケーキ       15500
カフェラテ     14850
コーヒー      14350
紅茶         4800
スコーン       4500
Name: sales, dtype: int64

この結果を見ると、サンドイッチ、ケーキ、カフェラテ、コーヒーの売上が近いことがわかります。

7. カテゴリ別に売上を集計する

商品名だけでなく、カテゴリごとにも売上をまとめてみます。category列でまとめると、ドリンク、デザート、フードのような大きなまとまりで比べられます。

category_sales = (
    df.groupby("category")["sales"]
      .sum()
      .sort_values(ascending=False)
)
print(category_sales)

実行結果は次のとおりです。

category
ドリンク     34000
デザート     20000
フード      16250
Name: sales, dtype: int64

今回のデータでは、カテゴリ別ではドリンクの売上がもっとも大きく、34,000円でした。次にデザートが20,000円、フードが16,250円です。

8. 一番売上が大きい商品を確認する

商品別売上合計の中で、一番売上が大きい商品名と金額をPythonで取り出してみます。

top_product = product_sales.idxmax()
top_sales = product_sales.max()
print(f"一番売上が大きい商品: {top_product}（{top_sales:,}円）")

実行結果は次のとおりです。

一番売上が大きい商品: サンドイッチ（16,250円）

9. 棒グラフで比べる

数字だけでも比べられますが、棒グラフにすると差が見やすくなります。

graph_labels = {
    "サンドイッチ": "Sandwich",
    "ケーキ": "Cake",
    "カフェラテ": "Cafe Latte",
    "コーヒー": "Coffee",
    "紅茶": "Tea",
    "スコーン": "Scone",
}
product_sales_for_graph = product_sales.rename(index=graph_labels)
plt.figure(figsize=(8, 4))
product_sales_for_graph.plot(kind="bar", color="#4F81BD")
plt.title("Sales by Product")
plt.xlabel("Product")
plt.ylabel("Sales (yen)")
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()

グラフでは、環境による日本語フォントの違いを避けるため、商品ラベルだけ英字にしています。棒の高さを見ると、サンドイッチが一番高く、ケーキ、カフェラテ、コーヒーがその近くに並びます。一方で、紅茶とスコーンはほかの商品より売上が小さめです。

10. 結果から読み取れること

今回のデータでは、売上合計は70,250円、1行あたりの売上平均は約4,391円でした。正確な計算結果は4,390.625円です。商品別ではサンドイッチが16,250円で最も高く、次にケーキが15,500円、カフェラテが14,850円と続きます。カテゴリ別では、ドリンクが34,000円で最も高くなりました。

この結果だけで「なぜ売れたのか」までは決められませんが、次に調べるテーマは考えられます。たとえば、サンドイッチは単価が高めなので売上が大きくなりやすいのか、ケーキやカフェラテと一緒に買われやすいのか、といった見方です。

まずは、CSVを読み、集計し、グラフにする。この小さな流れを自分で動かしてみることが大切です。
