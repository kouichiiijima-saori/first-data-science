# 記事編集機能 操作ガイド

本ドキュメントは、「はじめてのデータサイエンス」管理画面における記事の作成・編集・画像挿入および公開操作の手順をまとめた操作説明書です。

---

## 1. 記事編集方式について

記事を作成する際、次の2つの編集方式から選択できます。

1. **Markdown（マークダウン）**
   - 記号（`#` や `-`, `**` など）を用いて文章構造や文字装飾を記述します。
   - 保存前に「プレビューを実行する」ボタンで安全に表示を確認できます。
2. **リッチテキスト（Joditエディタ）**
   - ツールバーのボタン操作で直感的に段落・見出し・文字色・文字サイズ・下線・リンク・画像を装飾できます。

> [!IMPORTANT]
> **保存後の編集方式変更について**
> 記事を一度保存した後は、誤動作やレイアウト崩れを防ぐため、編集方式（Markdown ↔ リッチテキスト）を変更することはできません。

---

## 2. 記事の新規作成手順

1. **管理画面へログイン**
   - `/admin/login` よりメールアドレスとパスワードを入力してログインします。
2. **新規作成画面を開く**
   - 管理画面の「新規記事作成」ボタンをクリックします。
3. **編集方式の選択**
   - 「編集方式」ドロップダウンから **Markdown** または **リッチテキスト** を選択します。
4. **基本情報の入力**
   - **タイトル**: 120文字以内（必須）
   - **概要**: 500文字以内（必須）
   - **タグ**: カンマ区切りで指定（例: `Python, 統計学, 機械学習` / 最大10件、1タグ50文字以内）
   - **公開状態**:
     - `下書き (draft)`: 管理画面でのみ確認・編集可能。一般公開画面には表示されません。
     - `公開中 (published)`: 保存と同時に一般公開画面へ表示されます。
5. **サムネイル画像（任意）**
   - 記事一覧のカードや詳細ヘッダーに表示する代表画像を選択します。

---

## 3. リッチテキストエディタの操作方法

### 3.1 文字装飾・見出し
- **段落・見出し**: 「通常段落」「見出し2」「見出し3」「見出し4」から選択します。
- **文字サイズ**: 「小 (`0.875rem`)」「標準 (`1rem`)」「大 (`1.25rem`)」「特大 (`1.5rem`)」の4段階から指定可能です。
- **文字色**: あらかじめ定義された固定カラーパレット（6色）から選択できます。
- **太字 / 斜体 / 下線**: テキストを選択して対応するボタンをクリックします。

### 3.2 リンクの挿入
- テキストを選択し「リンク」ボタンをクリックして URL を設定します。
- セキュリティ保護のため、`http://` または `https://` で始まる safe URL のみが許可されます。

### 3.3 本文画像のアップロードとサイズ変更
1. エディタツールバーの **「画像」** ボタンをクリックします。
2. ファイル選択ダイアログから画像を選択すると、カーソル位置へ画像が挿入されます。
3. **サイズ変更**:
   - 挿入された画像をクリックすると、四隅にハンドルが表示されます。
   - ハンドルをドラッグして表示幅・高さを任意に調整できます（縦横比は自動維持されます）。

---

## 4. 画像に関する制限事項と注意点

### 4.1 画像の種類と容量
- **使用可能フォーマット**: `JPEG` (`.jpg`, `.jpeg`), `PNG` (`.png`), `WebP` (`.webp`)
- **許可されないフォーマット**: `SVG`, `GIF`, `PDF`, `HTML` など（選択してもエラーメッセージが表示されます）
- **容量上限**: **1ファイルあたり 5MB 以下**

### 4.2 サムネイル画像と本文画像の違い
- **サムネイル画像**: 記事自体に1枚添付され、記事一覧カードに配置される代表画像です。
- **本文画像**: 記事本文の任意の位置に埋め込まれる説明図やスクリーンショットです。

### 4.3 画像管理に関する現仕様（運用の注意事項）
- **保存前の未保存画像**:
  - 本文画像をアップロードした後に、記事を保存せず画面を閉じた場合、アップロードされた画像ファイルがサーバー上に一時的に残る場合があります。
- **本文からの画像除去**:
  - エディタ上で本文から画像を削除して記事を保存しても、画像ファイル自体はサーバーから物理削除されません（過去の保存履歴や誤削除防止のため）。
  - ※これらの不要画像クリーンアップは将来の保守運用タスク（orphan cleanup）で実施されます。

---

## 5. 保存と再編集

1. **保存**
   - フォーム下の **「保存する」** ボタンをクリックします。
   - 入力内容に不備（文字数超過など）がある場合、エラーメッセージが表示され、入力した文章や画像・指定サイズはそのまま保持されます。
2. **再編集**
   - 記事一覧画面から「編集」をクリックします。
   - 保存された文章、装飾、画像、サイズ指定がそのままエディタ上に復元され、再編集・再保存が可能です。
